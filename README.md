# GOOM

Run Doom in Go, using the [WASP](https://github.com/tarcisiozf/wasp) WebAssembly VM.

## Running

### Compile it
```bash
make build
```

### Run it

To be able to run the game, you need to provide a WAD file. You can use the shareware version of Doom, which is available for free.

```bash
./goom <path-to-wad-file>
```
